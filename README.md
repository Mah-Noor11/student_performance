# student_performance_prediction

## Project Overview
This project uses Machine Learning to predict students' final academic scores based on their study habits and academic performance.

## Objective
The main objective is to explore how different academic factors contribute to student performance and build a predictive model using a Random Forest Regressor.

## Input Features
- Study Hours
- Attendance
- Previous Score
- Assignment Completion

## Machine Learning Algorithm
Random Forest Regressor

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Dataset
A synthetic dataset containing 200 student records was created for this project.

## Expected Output
The model predicts a student's final score based on the provided input features.
